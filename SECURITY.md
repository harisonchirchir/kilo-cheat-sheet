# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Kilo Code or this cheat sheet, please report it responsibly.

### How to Report

1. **Email** the details to: security@kilocode.ai
2. **Do NOT** open a public issue
3. Include as much detail as possible:
   - Description of the vulnerability
   - Steps to reproduce
   - Impact assessment
   - Any proof of concept

### What We'll Do

- Acknowledge receipt within 48 hours
- Work with you to understand and validate the issue
- Coordinate disclosure timeline
- Push fixes as appropriate

## Best Practices

- Keep dependencies updated
- Use environment variables for secrets
- Review permissions before granting access
- Follow the principle of least privilege

## Scope

This policy covers the Kilo Code cheat sheet repository and associated documentation. For the core Kilo Code application security, please contact the maintainers directly.
