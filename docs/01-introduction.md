# Introduction to Kilo Code

## What is Kilo Code?

Kilo Code is an open-source AI coding agent designed to help developers understand, create, modify, test, and maintain software projects.

Unlike a traditional code-completion tool that primarily suggests code as you type, Kilo Code can work across an entire project. It can inspect files, understand existing implementations, propose changes, execute terminal commands, investigate errors, and assist with development workflows.

Kilo Code works with AI models from supported providers. The selected model influences the quality, speed, capabilities, and cost of the responses.

Its primary purpose is to make AI assistance part of the software development process while allowing developers to control how the agent interacts with their codebase.

## Key Features

- **AI-Powered Code Generation** - Write code from natural language descriptions
- **Context-Aware Assistance** - Understands your codebase and project structure
- **Multi-Agent Support** - Different AI agents for different tasks
- **Real-Time Collaboration** - Share coding sessions with your team
- **Extensible Architecture** - Custom agents, skills, and MCP servers
- **Git Integration** - Seamless integration with version control

## How Kilo Code Works

Kilo Code operates through an interaction cycle between the developer, the AI model, and the development environment.

A typical interaction follow these steps:

1. **Developer instruction**: You describe a task, problem, or desired outcome.
2. **Context gathering**: Kilo Code examines relevant project files, instructions, and available tools.
3. **Planning**: The agent determines the steps needed to complete the task.
4. **Tool execution**: Depending on permissions, it can read files, edit code, execute commands, and use configured integrations.
5. **Review**: You inspect the proposed changes and command results.
6. **Iteration**: You provide feedback or additional instructions until the task is complete.

The exact interaction depends on the selected agent, interface, model, and permission configuration.
