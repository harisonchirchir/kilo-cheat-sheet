# Kilo Code Cheat Sheet

### Commands.Shortcuts,Tips & Workflow

A practical, community-driven reference guide for developers using Kilo Code. Learn how to configure Kilo, work with AI agents, use CLI commands, manage context, automate development tasks, and improve your software engineering workflow.

## Overview

Kilo Code is a powerful AI coding assistant designed to help developers write better code faster. This cheat sheet provides quick reference documentation covering installation, configuration, agents, modes, commands, and best practices.

## Documentation Compatibility

Kilo Code evolves continuously. Commands, configuration options, shortcuts, and supported features may change between releases and interfaces.

This guide aims to distinguish between:

- Kilo Code VS Code extension.

- Kilo Code CLI.

- Other supported Kilo development interfaces.

- Current features and legacy functionality.
